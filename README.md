# Almohtaref Company Website | موقع شركة المحترف

**[Visit the live storefront](https://almohtaref-company-ui.pages.dev/)** · **[جرّب الموقع](https://almohtaref-company-ui.pages.dev/)**

A bilingual product catalog and admin dashboard built for Almohtaref Company, a supplier of computers, printers, surveillance systems, and networking equipment. Customers can explore the catalog and send their cart as an order request via WhatsApp. Company staff can manage the catalog from a dedicated dashboard.

هذا المشروع يجمع بين موقع عام لعرض منتجات شركة المحترف وخدماتها ولوحة إدارة للشركة. الموقع يدعم العربية والإنجليزية، ويتيح تصفّح المنتجات وعرض الأسعار بالدولار والليرة السورية وإرسال طلب السلة عبر واتساب.

## Features

- **Public storefront** — Browse products by category and brand, open shareable product pages with images and specifications, and switch between Arabic and English with RTL and LTR layouts.
- **Pricing and cart** — View prices in USD or SYP, add products to a cart, and send an order request through WhatsApp.
- **Admin dashboard** — Manage products, categories, brands, services, and administrator accounts. Staff can update SYP prices in bulk from USD prices using an entered exchange rate.

## My contribution

I worked across the Angular storefront and admin dashboard, the ASP.NET Core REST API, and the SQL Server data model. My work included catalog browsing and filtering, product detail pages, dual-currency pricing, and catalog management workflows.
